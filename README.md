# ANIMA Center

Сайтът на ANIMA Center (масаж и кинезитерапия, ул. „Лавеле“ 11, София), построен на
**React + Vite**. Дизайнът произхожда от темплейта Flexora (WordPress/Elementor),
но съдържанието, логото, снимките, цветовете и навигацията са на центъра.

Дълго тире (U+2014) няма никъде: нито в текстовете, нито в кода.
`tools/check-text.mjs` проверява и двете.

## Стартиране

```bash
npm install
npm run dev      # локален сървър на http://localhost:5173
npm run build    # продукционен билд в dist/
npm run preview  # преглед на билда
```

## Къде какво се пипа

> **Снимки:** секциите ползват визуалния материал на темплейта. Фоновете на
> хероя и на призива за записване са едно и също локално видео, пуснато от
> различна секунда, защото вграденият YouTube плеър рисуваше собствените си бутони
> върху кадъра и те не можеха да бъдат скрити отвън. Реалните снимки на
> центъра се показват само в **Галерия**, плюс портрета на терапевта и двете
> оферти.

| Искаш да смениш | Файл |
| --- | --- |

| Адрес на системата за онлайн резервации | `src/content/site.js` → `contacts.bookingUrl` |
| Цени и описания на услуги | `src/content/site.js` → `massages`, `faceTreatments` |
| Снимки в галерията | `src/content/site.js` → `gallery` |
| Оферти (офис масаж, курс) | `src/content/site.js` → `offers` |
| Данни за терапевта | `src/content/site.js` → `therapist` |
| Пунктове в менюто | `src/content/site.js` → `nav` |

| Заглавие, описание, икона, SEO | `index.html` |

## Структура

```

src/
  main.jsx                  монтира React, после зарежда наследения runtime
  App.jsx                   подредбата на секциите
  content/site.js           цялото съдържание на едно място
  components/
    SiteHeader.jsx          собствен header + мобилно чекмедже + call bar
    SiteFooter.jsx          контакти, Google карта, колони
    Icons.jsx               inline икони
    Modal.jsx               общият слой за модалите (портал към body)
    BookingModal.jsx        избор: обаждане или онлайн заявка
    sections/               секциите на страницата
  legacy/
    runtime-manifest.js     генериран списък със скриптовете на темата
    bootLegacyRuntime.js    зарежда ги в правилния ред след монтирането
    lazyBackgrounds.js      пуска lazy фоновете на Elementor
    pauseOffscreenMedia.js  спира видеата, които не се виждат
  styles/
    anima.css               марков слой + поправки по темата
    sections.css            новите секции
    modal.css               модалите
public/
  brand/                    оригиналното SVG лого + иконки за таба
  media/                    оптимизирани снимки на центъра (WebP + JPEG)
  images/                   оригиналните снимки, от които се генерират
  wp-content/, wp-includes/ CSS и JS на темата, не се пипат на ръка
```

### Как работи наследеният runtime

Анимациите при скрол, каруселите (Swiper), акордеонът и паралаксът идват от
оригиналния JavaScript на Elementor. `main.jsx` първо рендерира React
синхронно (`flushSync`), защото Elementor чете DOM-а в момента, в който се
изпълни, и чак тогава вкарва скриптовете в точния ред, с `async = false`, за
да не изпуснат събитието `window.load`.

**Появата на секциите обаче не е негова работа.** Маркупът на Elementor слага
`elementor-invisible` (`visibility: hidden`) на всеки анимиран елемент и чака
своя рънтайм да я махне. Това значеше, че целият текст на горната
половина от сайта виси на двайсетина външни скрипта: падне ли един от тях
(jQuery, webpack runtime, elementor frontend), посетителят вижда само фоновете.
Затова `src/legacy/revealAnimations.js` поема появата с собствен
IntersectionObserver преди стария рънтайм и маха анимационните ключове от
`data-settings`, за да не анимира Elementor същия елемент втори път. Ако и
той не се изпълни, `html:not(.anima-reveal)` в `anima.css` оставя всичко
видимо. За проверка: `node tools/check-reveal.mjs`.

## Инструменти (`tools/`)

Не са част от сайта, но с тях е направен и се поддържа:

| Скрипт | За какво |
| --- | --- |
| `make-logo.mjs` | иконките за таба от векторното лого |
| `make-photos.mjs` | реже и оптимизира снимките в `public/media` |
| `swap-images.mjs` | сменя стокови снимки с реални в секциите |
| `remove-symbol-icons.mjs` | маха декоративната иконка на темата |
| `brand-book-buttons.mjs` | оформя бутоните „Запази час“ в секциите |
| `sample-logo.mjs` | вади цветовете на марката от логото |
| `check-modals.mjs` | проверява прозорците за записване и галерията |
| `check-hover.mjs` | мери контраста на бутоните при hover |
| `check-media.mjs` | проверява, че видеата спират извън екрана |
| `check-palette.mjs` | обхожда сайта и вдига тревога при зелен тон |
| `check-text.mjs` | търси дълги тирета (U+2014) в текстовете и в кода |
| `check-reveal.mjs` | секциите излизат дори с паднал рънтайм на темата |
| `footer-variants.mjs` | рендерира футъра в няколко тона за сравнение |
| `restore-images.mjs` | връща стоковите снимки на темплейта |
| `audit-responsive.mjs` | проверява 10 размера екран за изнасяне, дребен шрифт и малки цели |
| `translate.mjs` | речник за превода на текстовете |
| `rewrite-head.mjs` | мета данните на `index.html` |
| `convert.mjs` | еднократната конверсия от HTML към React (изисква `--force`) |
| `shoot.mjs`, `verify.mjs` | снимки и проверка в headless Chrome |

След смяна на снимка в `public/images` пусни `node tools/make-photos.mjs`
(с име накрая - само тази снимка: `node tools/make-photos.mjs office-massage`).

## Какво още чака данни

- **Адресът на платформата за резервации.** Бутонът „Запази час онлайн“
  е готов и стои първи в прозореца за записване. Докато `contacts.bookingUrl`
  е празен, се показва изключен, с бележка „скоро“. Попълни адреса и става
  истинска връзка към платформата, без друга промяна по кода.
- **Отзиви** няма: секцията от темплейта беше с измислени клиенти и е махната.
  Като имаш реални, казвай, има готово място за тях.

## Проверка преди качване

```bash
npm run build
npx sirv-cli dist --port 5002 --dev --quiet &

node tools/audit-responsive.mjs   # 10 размера екран
node tools/check-hover.mjs        # контраст на бутоните при hover
node tools/check-modals.mjs       # записване на час + галерия
node tools/check-media.mjs        # видеата спират извън екрана
node tools/check-palette.mjs      # никъде няма зелено
node tools/check-text.mjs         # няма дълги тирета (и в кода)
node tools/check-reveal.mjs       # текстовете излизат и без скриптовете на темата
```

Минава през 10 размера екран (от iPhone SE 320px до 1920px, включително телефон
в легнало положение) и съобщава хоризонтално изнасяне, счупени заявки, грешки в
конзолата, цели под 40px и текст под 12px на тъч устройства.
